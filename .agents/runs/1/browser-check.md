## やったこと

- 全5ページ(index / menu / about / access / contact)を、幅 320 / 375 / 768 / 1280px で実レンダリング
- 各ページ・各幅で横方向のはみ出し(scrollWidth − clientWidth)と JS エラー(console / pageerror)を計測
- スクリーンショット取得：トップ(375px 全文・1280px)、メニュー(375px)、アクセス(375px) → `preview/` に保存

## 結果

- **はみ出し：全20条件で 0**。要素単位の犯人探しも不要だった
- **JSエラー：全条件で 0件**
- 目視：スマホの固定下部バー(電話する／地図を見る／メニュー)、今週の営業日(11/10 定休日・11/12 臨時休業の色分け+文字表示)、デモ告知の上下配置、QR設置位置のプレースホルダを確認
