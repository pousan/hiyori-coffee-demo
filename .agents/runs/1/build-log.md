## 根拠

1. **ファイル構成・静的完結性の確認**
   - 設計書「4. ファイル構成」の9ファイルがすべて存在し、外部フォント・外部画像URL・外部スクリプト・地図APIへの参照が一切ないこと（`http://` / `https://` / `tel:` が0件であること）をスクリプトで検査して確認した。
2. **HTML構造・リンク・アクセシビリティ検証**
   - 全5ページに `lang="ja"`、`viewport`、`<meta name="robots" content="noindex, nofollow">`、ページ固有の `<title>`（「〇〇｜ひより珈琲（架空カフェのデモ）」形式）および `<meta name="description">` を設定した。

   - `contact.html` の全フォームコントロール（6項目）に明示的な `<label for="...">` が紐付いていることを確認した。
3. **WCAGコントラスト比の計算確認**
   - 設計トークンの文字色と背景色の組み合わせについてWCAG 2.1相対輝度からコントラスト比を算出し、すべて基準の `4.5:1` 以上であることを確認した：
     - 本文色 `#302D28` / 基調背景 `#FAF6EF`：**12.73:1**
     - 本文色 `#302D28` / 面の色 `#FFFDF8`：**13.49:1**
     - 補助文字色 `#625B52` / 基調背景 `#FAF6EF`：**6.21:1**
     - 補助文字色 `#625B52` / 面の色 `#FFFDF8`：**6.58:1**
     - 深緑 `#24483E` / 基調背景 `#FAF6EF`：**9.41:1**（淡緑背景 `#E9F0ED` 上でも **8.76:1**）
     - 焙煎ブラウン `#795039` / 基調背景 `#FAF6EF`：**6.46:1**
     - 休業・エラー色 `#8B3F35` / 基調背景 `#FAF6EF`：**6.82:1**（淡赤背景 `#F9ECEA` 上でも **6.37:1**）
4. **JavaScript動作検証（Node.js VM による単体・結合テスト）**
   - `business-hours.js`：トップの週カード一覧（7件）とアクセスページの週カレンダー（7列）＋詳細一覧（7件）が同一データから描画され、11/10（火）が「定休日」、11/12（木）が通常営業より優先されて「臨時休業」となること、対象期間「表示例：2026年11月9日〜15日」と共通ステータス「営業日サンプルを表示しています。」が出力されることを確認した。
