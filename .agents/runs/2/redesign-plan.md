# 再設計プラン — run 2(デザイン魅力の改善)

作成：もち／2026-11-08。ユーザーの指摘「内容的には満足。デザインが魅力的ではない」を受けた修正ラウンド。
担当：計画＝もち、実装＝agy、検証＝もち(実ブラウザのスクリーンショット)。今回は視覚・嗜好の修正であり、Codex の枠を節約するため計画はもちが担う。

## agy のスキル調査結果

agy 組み込みスキル13件を確認した。大半は Antigravity 自体の操作・移行・自動化用で、デザインに使えるのは **`generative_ui`** のみ。

取り入れる原則(generative_ui より):
- カード基調のレイアウトにエレベーション(影)を与え、要素を「浮かせる」
- 余白で呼吸を作る。詰め込まない
- クリーンでプレミアムな見た目を目指す
- 小さすぎる文字を使わない(既存ルール「本文16px以上・注記14px以上」と一致)

採らないもの: generative_ui 推奨の Tailwind CDN は、本サイトの設計判断「外部通信ゼロ」と衝突するため使わない。原則だけを既存の素の CSS に翻訳する。

## 現デザインの課題(スクリーンショット所見)

1. 写真がなく、CSS の線イラストが空虚で安く見える ← 最大の弱点
2. 全面が生成り一色で単調。画面のリズムがない
3. 見出しが地味(ゴシック同サイズ感)で、店の個性が出ない
4. カードに影がなく平坦。セクションの境目が弱い

## 変更内容

### 1. 写真を入れる(生成済みイメージ写真 7 点、site/images/)

すべて架空の店のイメージ写真として生成し、掲載箇所には「イメージ写真」の注記を維持する。

### 2. レイアウト・タイポグラフィ

- ヒーロー: 写真を主役に(スマホは写真上部+見出し重ね or 写真→見出しの縦積み、PC は写真右 55%)。CSS イラストは廃止
- 見出しフォント: 明朝系のシステムフォント("Hiragino Mincho ProN", "Yu Mincho", serif)を h1/h2 に。本文ゴシックは維持
- セクションラベル: 各セクション見出しの上に英字の小ラベル(TOPIC 風: "WEEKLY SCHEDULE" 等)を深緑で添える
- リズム: 「今週の営業日」セクションを深緑の帯(背景)にし、白カードを浮かせる。その他は生成りのまま
- カード: 写真付きカードに統一し、影(box-shadow)と角丸 12px。トップの「ひよりの時間」3 カードに写真を載せる
- メニュー: 写真付き 3 品(トーストセット、ブレンド、焼きケーキ)を特集カードにし、残りは従来のテキスト行

### 3. 維持する制約(run 1 の受け入れ済み事項)

- 文字サイズ下限(本文 16px 以上、注記 14px 以上)、余白スケール、コントラスト 4.5:1 以上
- 営業日 JS・フォーム JS・固定下部バーの動作は無変更
- 外部通信ゼロ(フォントもシステムフォントのみ)、デモ告知の上下配置
- 実在素材・口コミ・受賞歴なし。価格・文案は原則無変更
