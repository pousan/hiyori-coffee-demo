### 計画からの変更点・補足判断と理由

- **計画からの変更点なし（`redesign-plan.md` どおりに実装）**
  - **ヒーローのDOM順と視覚順の両立**：DOM上はテキスト・主要導線を先に保ちつつ、スマホ表示（767px以下）では `.hero-media { order: -1; }` で写真を上部に表示し「スマホ: 写真と見出しの縦積み / PC: 写真右55%（`grid-template-columns: 9fr 11fr`）」を実現した。
  - **深緑帯（`今週の営業日`）上の英字ラベルと休業カードの視認性**：深緑背景（`#24483E`）上でも英字小ラベルが「深緑の文字色」かつコントラスト比4.5:1以上を満たすよう、帯セクション内の `.section-label` には淡緑ピル背景（`#E9F0ED`）＋深緑文字（`#24483E`、コントラスト **8.76:1**）を適用した。また帯上の7日分カード（`.weekly-card`）はすべて白背景（`#FFFDF8`）＋強い影（`--shadow-card-strong`）で浮かび上がらせ、休業日は赤茶のアクセントボーダーと「定休日／臨時休業」バッジ・文字で識別できるようにした。
  - **フッターの「QR設置位置」枠の維持**：フッターのInstagram・口コミ案内にある「QR設置位置」枠は `design.md` の「読み取れるQRコードや実在アカウントは使わない」規定に基づく機能的プレースホルダであるため維持し、本文エリアのCSSイラスト4種（窓辺・モーニング・焙煎機・道順アイコン）をすべて生成写真へ置き換えた。

## 根拠

1. **画像7点の網羅・`alt`・注記・旧CSSイラスト廃止の確認**
   - PythonのHTMLParser検証スクリプトにより、`site/images/` の全7ファイルが漏れなく参照・実在し、全 `<img>` タグ（延べ10箇所）に内容を表す `alt` と `width="1600" height="1067"`、および14px（`0.875rem`）の「イメージ写真」注記（`.photo-caption`）が付与されていることを確認した。
   - 全HTMLおよび `style.css` から旧CSSイラスト用の `.illus-*` クラスが0件になっていることを確認した。
2. **文字サイズ・フォント・余白スケールの検証**
   - `style.css` の `--font-serif` を `"Hiragino Mincho ProN", "Yu Mincho", serif` に設定し、`h1`・`h2`・店名ロゴに適用した。
   - `style.css` 内の全 `font-size` 宣言を検査し、最小値が `0.875rem`（14px：注記・ラベル・カレンダー等）、本文・商品説明・ボタン・フォーム入力欄が `1rem`（16px）以上であることを確認した。
   - `style.css` 内の全 `padding` / `margin` / `gap` 宣言（166箇所）およびHTML内インラインスタイルを検査し、すべて設計スケール（`0 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80px`、コンテナ横余白 `20px`、`.sr-only` の `-1px`）内の値であることを確認した。
3. **WCAGコントラスト比（4.5:1以上）の計算確認**
   - 深緑帯セクション（`.section-green-band`）および写真キャプションを含む全配色の相対輝度コントラスト比を算出し、すべて4.5:1以上であることを確認した：
     - 深緑帯上の見出し（`#FFFDF8` / `#24483E`）：**9.97:1**
     - 深緑帯上の英字小ラベル（`#24483E` / `#E9F0ED`）：**8.76:1**
     - 深緑帯上のボタン（`#24483E` / `#FFFDF8`）：**9.97:1**（hover時 `#302D28` / `#E9F0ED`：**11.85:1**）
     - 写真上の「イメージ写真」注記（`#625B52` / 不透明 `#FFFDF8` 背景）：**6.58:1**
     - 通常セクションの深緑英字小ラベル（`#24483E` / `#FAF6EF`）：**9.41:1**
     - 白カード上の本文（`#302D28` / `#FFFDF8`）：**13.49:1**、補助文字（`#625B52` / `#FFFDF8`）：**6.58:1**、休業文字（`#8B3F35` / `#FFFDF8`）：**7.22:1**
4. **外部通信ゼロ・既存JS不変の確認**
   - 全HTML/CSS/JSファイルに `http://` / `https://` / `tel:` 等の外部通信参照が0件であることを確認した。
   - `git status` により `site/js/main.js`、`site/js/business-hours.js`、`site/js/contact.js` に一切変更がないことを確認した。
